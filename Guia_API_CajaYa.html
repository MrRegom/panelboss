Sistema de Sincronización de Catálogo Maestro

🔑 Credenciales de Desarrollo

Para facilitar el proceso de integración, hemos habilitado una licencia de pruebas con acceso total al catálogo de +7,000 productos.

Campo Valor de Prueba Uso
LICENSE_KEY DEVELOPER-TEST Llave maestra para todas las peticiones
EMPRESA CajaYa Desarrollo Entorno de simulación POS

1 Sincronización de Productos

Este endpoint devuelve el catálogo completo en formato JSON de alta velocidad.

GET https://panel.cajaya.cl/api/catalog/list.php?license_key=DEVELOPER-TEST

💻 Prueba Rápida (cURL)

Copia y pega este comando en tu terminal para validar la conexión inmediatamente:

curl -X GET "https://panel.cajaya.cl/api/catalog/list.php?license_key=DEVELOPER-TEST"

Estructura de Respuesta:

{
  "success": true,
  "count": 7240,
  "data": [
    {
      "barcode": "8434165469037",
      "name": "Galleta Diet Sandwich De Cacao Gullón 210Gr",
      "brand": "Gullón",
      "category_name": "Snacks y Galletas",
      "image_url": "https://panel.cajaya.cl/api/catalog/image.php?barcode=8434165469037&license_key=DEVELOPER-TEST"
    }
  ]
}

2 Gestión de Imágenes

Las imágenes se sirven de forma dinámica. El sistema detecta automáticamente el código de barras y valida la licencia para servir el recurso binario.

GET https://panel.cajaya.cl/api/catalog/image.php?barcode={BARCODE}&license_key=DEVELOPER-TEST

* Nota: El parámetro image_url devuelto en el catálogo ya contiene el enlace completo listo para usar.

⚠️ Protocolo de Implementación:

Se recomienda realizar la sincronización completa una vez al día o bajo demanda del usuario. El sistema soporta compresión GZIP para transferencias masivas de datos.
