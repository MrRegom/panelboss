Documentación de API

Guía de integración para el Catálogo Maestro de Productos v1.0

Estatus: Activa

1. Introducción

Esta API permite a la aplicación móvil o de escritorio de CajaYa sincronizar y consultar el catálogo global de productos de forma segura. La validación se realiza mediante una clave de licencia activa.

Servidor Base: https://api.cajaya.cl/catalog/

2. Autenticación

Para endpoints de sistema (Activación, Heartbeat), se requiere el envío del siguiente header:

X-Client-Id: {TU_API_KEY}

3. Credenciales de Desarrollo

Para la fase de integración, utilice la siguiente clave maestra:

LICENSE_KEY: DEVELOPER-TEST

4. Sincronización de Productos

Retorna el listado completo de productos validados en el sistema.

GET /list.php

Parámetro Tipo Descripción
license_key String Clave de licencia activa (Obligatorio).

Ejemplo de Respuesta JSON:

{
  "success": true,
  "count": 7342,
  "data": [
    {
      "barcode": "7802237001217",
      "name": "7 Especias Suk 70Gr",
      "category": "Despensa",
      "image_url": "https://api.cajaya.cl/catalog/image.php?barcode=7802237001217&license_key=DEVELOPER-TEST"
    }
  ]
}

4. Carga de Imágenes

Servicio para la entrega de archivos binarios de imagen.

GET /image.php

Parámetro Tipo Descripción
barcode String Código EAN del producto.
license_key String Clave de licencia activa.

Uso Recomendado:

Utilice la URL generada en el campo image_url del listado para alimentar componentes visuales de la aplicación.
